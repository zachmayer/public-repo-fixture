# Contributing

Thanks for your interest in contributing! To keep things smooth for everyone:

1. **Discuss larger changes first.** Open an issue to describe the problem or proposal before starting significant work, so effort is not duplicated or wasted.
2. **Keep pull requests focused.** Each PR should address one change, with a clear description of what changed and why.
3. **Check your work before requesting review.** Run the existing tests and linters, and add or update tests for any behaviour you change.
