# Contributing

Thanks for your interest in contributing. Please keep the following in mind when opening changes:

1. **Keep changes focused.** Open one pull request per logical change, and describe what it does and why in the pull request description.
2. **Check your work before submitting.** Run the project's existing tests and checks, and make sure your change does not introduce new failures or warnings.
3. **Be respectful in discussions.** Give constructive feedback on code and ideas, and assume good intent from other contributors.
