# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** For anything beyond a small fix, open an issue describing the change so it can be discussed before you start work.
2. **Keep pull requests focused.** Each pull request should address a single change, with a clear title and a description of what it does and why.
3. **Be respectful.** Keep discussion constructive and courteous in issues, reviews, and comments.
