# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** Before starting significant work, open an issue describing the problem or proposal so maintainers can provide feedback early.
2. **Keep pull requests focused.** Each pull request should address a single concern, include a clear description of the change, and add or update tests where applicable.
3. **Be respectful and constructive.** Treat all participants with courtesy in issues, reviews, and discussions.
