# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** Before starting significant work, open an issue to discuss the change so we can agree on the approach.
2. **Keep pull requests focused.** Each PR should address a single concern, include a clear description of what changed and why, and keep the commit history tidy.
3. **Follow existing conventions and add tests.** Match the style of the surrounding code, update documentation where relevant, and add or update tests for any behavior you change.
