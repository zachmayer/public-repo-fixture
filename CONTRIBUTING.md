# Contributing

Thanks for your interest in contributing! To keep changes easy to review:

1. **Keep changes focused.** Open one pull request per logical change, and describe what it does and why in the PR description.
2. **Check your work before submitting.** Run the project's tests and linters locally, and make sure your branch is up to date with the default branch.
3. **Be respectful in discussions.** Give constructive feedback on code rather than on people, and be open to revising your changes based on review.
