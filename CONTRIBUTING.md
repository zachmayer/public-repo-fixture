# Contributing

Thanks for your interest in contributing. Please keep these guidelines in mind:

1. **Discuss larger changes first.** Open an issue to describe the problem and proposed approach before starting significant work, so effort is not duplicated or spent on a direction that won't be merged.
2. **Keep changes focused.** Each pull request should address one logical change, with a clear description of what changed and why.
3. **Test and document your work.** Run the existing checks before submitting, add tests for new behaviour, and update the documentation when your change affects how the project is used.
