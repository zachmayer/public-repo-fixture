# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Keep changes focused.** Make each pull request address a single issue or concern, and describe what changed and why in the PR description.
2. **Test your changes.** Run the existing tests and checks before opening a pull request, and add tests for new behaviour where practical.
3. **Be respectful and constructive.** Write clear, courteous review comments and be open to feedback on your own work.
