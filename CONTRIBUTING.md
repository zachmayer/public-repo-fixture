# Contributing

Thanks for your interest in contributing! Please keep the following in mind:

1. **Keep changes focused.** Make one logical change per pull request, and describe clearly what it does and why.
2. **Test your changes.** Run the existing checks and add or update tests where relevant before requesting review.
3. **Be respectful in discussions.** Give constructive feedback, assume good intent, and be open to revising your work based on review.
