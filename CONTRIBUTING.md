# Contributing

Thanks for your interest in contributing. Please follow these guidelines when opening issues or pull requests:

1. **Keep changes focused.** Make one logical change per pull request, and describe what it does and why in the PR description.
2. **Test your changes.** Run the existing tests and checks before submitting, and add tests for new behaviour or bug fixes where practical.
3. **Be respectful and constructive.** Write clear, specific feedback in reviews and issues, and be open to revising your work based on review comments.
