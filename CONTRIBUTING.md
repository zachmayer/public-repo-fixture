# Contributing

Thanks for your interest in contributing. To keep changes easy to review:

1. **Keep changes focused.** Make one logical change per pull request, and describe what it does and why in the PR description.
2. **Check your work before opening a PR.** Confirm that the project builds and any existing tests pass, and add tests for new behaviour where practical.
3. **Be respectful in discussions.** Give constructive feedback on code rather than on people, and be open to revising your approach based on review.
