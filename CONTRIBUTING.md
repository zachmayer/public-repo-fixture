# Contributing

Thanks for your interest in contributing! Please keep the following guidelines in mind:

1. **Discuss larger changes first.** Open an issue before starting significant work so the approach can be agreed on before you invest time in it.
2. **Keep pull requests focused.** Each pull request should address a single change, with a clear title and a description that explains what changed and why.
3. **Check your work before requesting review.** Make sure the project's tests and linters pass locally, and update documentation affected by your change.
