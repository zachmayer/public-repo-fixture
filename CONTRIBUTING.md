# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** For anything beyond a small fix, describe the change you have in mind so it can be discussed before you invest time.
2. **Keep changes focused.** Make small, self-contained pull requests with clear commit messages, and follow the existing code style.
3. **Test your changes.** Add or update tests where relevant and make sure existing tests pass before requesting review.
