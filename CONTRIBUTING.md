# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** For anything beyond a small fix, open an issue to discuss the change before starting work.
2. **Keep pull requests focused.** Each pull request should address a single concern, with a clear description of what changed and why.
3. **Write clear commit messages.** Use a short summary line in the imperative mood (e.g. "Fix typo in README"), followed by more detail if needed.
