# Contributing

Thanks for your interest in contributing. A few guidelines to keep changes easy to review:

1. **Keep changes focused.** Make one logical change per pull request, and describe what it does and why in the PR description.
2. **Test your changes.** Run the existing checks, and add or update tests where behaviour changes, before requesting review.
3. **Be respectful in discussions.** Give constructive feedback on code rather than on people, and assume good intent from reviewers and other contributors.
