# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** Before starting significant work, open an issue describing the problem or proposal so it can be discussed.
2. **Keep pull requests focused.** Each pull request should address a single concern, include a clear description, and reference any related issues.
3. **Follow the existing style and add tests.** Match the conventions already used in the codebase, and include tests or documentation updates for any behavior you change.
