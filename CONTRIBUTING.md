# Contributing

Thanks for your interest in contributing. Please follow these guidelines when opening issues or pull requests.

1. **Keep changes focused.** Make one logical change per pull request, and describe what it does and why in the PR description.
2. **Test your changes.** Run the existing checks and add or update tests where behaviour changes before requesting review.
3. **Be respectful in discussions.** Give constructive feedback, assume good intent, and be open to revising your approach based on review.
