# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** For anything beyond a small fix, open an issue describing the change so it can be discussed before you invest time in a pull request.
2. **Keep pull requests focused.** Each pull request should address a single concern, with a clear title and a description of what changed and why.
3. **Write clear commit messages.** Use a short imperative summary line (e.g. "Fix typo in README"), followed by more detail in the body if needed.
