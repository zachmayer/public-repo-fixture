# Contributing

Thanks for your interest in contributing! Please keep the following guidelines in mind.

1. **Discuss larger changes first.** Open an issue to describe a significant change before starting work on it, so the approach can be agreed on early.
2. **Keep pull requests focused.** Make each pull request address a single change, and describe what it does and why in the description.
3. **Check your work before requesting review.** Make sure existing tests and linters pass, and add tests for any new behaviour.
