# Contributing

Thanks for your interest in contributing to this project. Please follow these guidelines:

1. **Open an issue first.** Before starting significant work, open an issue describing the change you'd like to make so it can be discussed.
2. **Keep pull requests focused.** Each pull request should address a single concern, with a clear title and description of what changed and why.
3. **Follow existing conventions.** Match the code style, formatting, and structure already used in the repository, and make sure any tests pass before submitting.
