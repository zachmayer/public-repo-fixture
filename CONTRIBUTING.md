# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first for significant changes.** Discuss larger features or refactors before starting work so effort isn't duplicated or wasted.
2. **Keep pull requests small and focused.** Each PR should address a single concern, include a clear description of what changed and why, and reference any related issues.
3. **Write clear commit messages and test your changes.** Use descriptive commit messages, and make sure existing tests pass (and add new ones where appropriate) before requesting review.
