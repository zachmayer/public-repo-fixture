# Contributing

Thanks for your interest in contributing. These guidelines help keep changes easy to review and the project easy to maintain.

1. **Keep changes focused.** Make each pull request address one issue or one logical change, and describe what it does and why in the pull request description.
2. **Test your changes.** Run the existing tests and checks before opening a pull request, and add tests for new behaviour or bug fixes where practical.
3. **Be respectful in discussions.** Assume good intent, give constructive feedback, and keep reviews focused on the code.
