# Contributing

Thanks for your interest in contributing. Please follow these guidelines when opening issues and pull requests.

1. **Keep changes focused.** Make each pull request address a single problem or feature, and keep unrelated edits out of it.
2. **Describe your changes.** Explain what changed and why in the pull request description, and link any related issues.
3. **Check your work before submitting.** Confirm the project builds and any existing tests pass locally before requesting review.
