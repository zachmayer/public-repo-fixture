# Contributing

Thanks for your interest in contributing. To keep changes easy to review, please follow these guidelines:

1. **Keep changes focused.** Make each pull request address one issue or one logical change, and describe what it does and why in the pull request description.
2. **Check your work before opening a pull request.** Run the project's tests and linters locally, and confirm that your change works as described.
3. **Be respectful in discussions.** Give constructive feedback on code and ideas, and assume good intent from other contributors.
