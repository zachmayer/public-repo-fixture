# Contributing

Thanks for your interest in contributing. Please follow these guidelines:

1. **Discuss larger changes first.** Open an issue to describe the problem or proposal before starting substantial work, so effort is not duplicated or spent on an approach that won't be merged.
2. **Keep changes focused.** Submit one logical change per pull request, and include a clear description of what changed and why.
3. **Check your work before submitting.** Make sure the project builds and any existing tests pass, and add tests for new behaviour where practical.
