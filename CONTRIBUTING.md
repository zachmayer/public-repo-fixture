# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** Before starting significant work, open an issue describing the change you'd like to make so it can be discussed.
2. **Keep pull requests focused.** Each pull request should address a single concern, include a clear description, and reference any related issues.
3. **Follow existing conventions.** Match the style of the surrounding code and documentation, and make sure any existing checks pass before requesting review.
