# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first for significant changes.** Discuss larger features or refactors before starting work so effort isn't duplicated or wasted.
2. **Keep pull requests small and focused.** Each PR should address a single concern and include a clear description of what changed and why.
3. **Write clear commit messages and test your changes.** Use descriptive, imperative-mood commit messages and make sure existing checks pass before requesting review.
