# Contributing

Thanks for your interest in contributing! To keep changes easy to review, please follow these guidelines:

1. **Keep changes focused.** Make each pull request address a single change, and describe what it does and why in the PR description.
2. **Check your work before submitting.** Run the project's tests and linters locally, and confirm your change works as described.
3. **Be respectful in discussions.** Give constructive feedback on code and proposals, and assume good intent from others.
