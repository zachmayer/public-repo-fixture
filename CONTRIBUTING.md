# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first for significant changes.** Describe the problem or proposal so it can be discussed before you invest time in a pull request.
2. **Keep pull requests small and focused.** Each PR should address a single concern, include a clear description of what changed and why, and update documentation where relevant.
3. **Write clear commit messages.** Use a short imperative summary line (e.g. "Fix typo in README"), followed by more detail in the body if needed.
