# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Discuss significant changes first.** Open an issue to describe the problem or proposal before starting substantial work, so effort is not duplicated or wasted.
2. **Keep pull requests focused.** Make one logical change per pull request, and describe what changed and why in the PR description.
3. **Check your work before requesting review.** Run the existing tests and linters locally and make sure they pass before asking for a review.
