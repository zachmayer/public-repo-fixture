# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** For anything beyond a small fix, open an issue describing the problem or proposal before starting work, so the approach can be agreed on early.
2. **Keep changes focused.** Each pull request should address a single concern, with a clear title and a description of what changed and why.
3. **Be respectful.** Keep discussion constructive and courteous in issues, reviews, and pull requests.
